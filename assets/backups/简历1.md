## 深度参与的项目

- 负责图像编辑基座模型中关于 tokenizer 的研发：
	- 背景：迈向“视觉/语言统一理解/生成的模型”，采取 autoregressive 范式，目标是实现 unified multimodal understanding/generation。
	- 动机：当前 autoregressive image generation 是 1D causal 的输出，而主流 image tokenizer 是 2D non-causal 的，这使得 inductive bias 不匹配，且 image generation 无法动态调整 token 预算。此外，我们还想探索并验证一种 representation 先验，那就是同一内容的不同分辨率图像应该有相同/相似的低频表征，其于高频表征解耦。
	- 方法：我提出了一种 single-stream、adaptive-length、适用于多分辨率的、专为 autoregressive image generation 打造的 tokenizer。它实现了将图像编码成为 1D causal 的 token 序列，同时可对其任意 prefix 进行解码得到重建图像。此外，通过创新的模型结构与训练方式，它从空域实现了对频域的解耦，具体来说，同一内容的不同分辨率图像编码后的 token 序列前缀是一致的，而一个 token 序列也可以被解码重建成同一内容的不同分辨率图像。
	- 效果：在 ImageNet 上，图像重建水平（rFID/SSIM/PSNR）在类似方法中取得 SOTA；并且能够在极大加速（8x）的同时，实现同模型大小下图像生成（gFID/IS）的 SOTA。
	- 论文：这项工作已经以第一作者投稿在 AAAI 2027 会议。
- 负责轻量世界模型中关于 dataset 与 post-training 的研发：
	- 背景：大众点评 APP 的用户评论场景，用户上传门店照片，并选择预设的“世界探索” prompt，世界模型要生成对应视频。
	- 动机：当前可以实现精确相机轨迹控制的 world model 通常需要显式相机外参或控制信号，然而这些输入在用户使用大众点评时无法获得。此外，主流 world model 过于庞大，即使经过 few-step distillation，仍然对实时交互式生成有不小的挑战，我们需要更轻量的模型。
	- 方法与贡献：我提出了一个构建高质量 world rollout 数据的 pipeline 并构造了一个 60k 视频规模的数据集，用于将任意 I2V 模型微调成 world model 进行 text-guided world generation。这个 pipeline 包含对真实视频进行清洗并利用 VLM 生成 annotation，用 teacher world model 大规模生成，用 VLM 进行 filtering。在此之后，我对两个 2B 的 off-the-shelf I2V 模型进行 LoRA 微调，并实现比基模更强的 world generation 能力。
	- 效果：分别对 Wan 和 CogX 的 2B 大小的 I2V 模型 LoRA 微调，均在 WorldScore 和 WorldModelBench 上超越原始能力（5% - 10%）。
	- 论文：这项工作已经以第一作者投稿在 AAAI 2027 会议。
